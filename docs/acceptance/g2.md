## 交付与范围

- `herdr-hub-core-bridge` 库：固定 hc 程序/会话，异步二进制桥接、EOF、取消及子进程回收。
- `herdr-hub-agent local-bridge`：显式本地开发命令，严格验证已知 bootstrap；
  不求值 shell、不监听网络端口、不处理注册/授权，不自动修改 hc machine 配置。
- 原生测试子程序 `herdr-hub-test-hc` 仅用于测试，不作为产品安装/分发；
  产品构建必须明确使用 `--bin herdr-hub-agent`。
- Windows 与 Linux 分别使用各自原生编译产物，不把 Windows exe 当作 Linux agent。

## 执行证据

Windows 和 WSL2/Linux 均使用 Rust 1.99.1 / hc 0.1.19。
WSL 编译由普通测试用户执行，使用独立 Linux target/cache；未改 Windows 工具链或 PATH。

```text

cargo clippy -p herdr-hub-core-bridge --all-targets --locked -- -D warnings: Windows exit 0

cargo test -p herdr-hub-core-bridge --locked --quiet: Linux 3 unit + 6 integration passed
```

最后等待子进程并保留退出码。三个聚焦用例和两平台原测试、clippy、真实 smoke 已通过，
当前 Windows/Linux 各 12 个用例，两位 reviewer 均确认无新增高置信阻塞。
